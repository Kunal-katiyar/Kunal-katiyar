# Hi, I'm Kunal! 👋

I'm Kunal, a first-year computer science student at the University of Texas at Austin. You can read more about my projects and skills below!

## Projects

### 🔭 What I'm working on right now:

* [**CE Planner**](https://github.com/Kunal-katiyar/CEPlanner): A React.js/Node.js website that automatically generates a college application planner inside of the user's Google Drive account, complete with essays and deadlines.
  * Uses parsed data from the internet (that I compiled myself).
  * Will autofill essays into an organized Google Doc, and place all essays in a Google Sheet for easy tracking


- **ScreenTimer**: An iOS/Swift mobile app that allows users to set custom, on-demand app restriction timers for themselves.
  - Supports Pomodoro and standard timers, as well as custom presets for easy access to common sessions.
 
 
### ✅ Projects I've completed:

* [**CollegeAppParser**](https://github.com/Kunal-katiyar/CollegeAppParser): A Python package that parses publicly available data to compile the deadlines and supplemental essays of most US colleges.
  - Contains support for manual data entries/revisions as well, and automatically sorts new entries alphabetically to allow for users to employ faster search algorithms.
  - I'm currently using the data I've compiled from this on my **CE Planner** project!
  - The data is also publicly available to download from the repository.
 
- [**FromHome**](https://github.com/Kunal-katiyar/fromhome): A Python (Flask) and HTML/CSS/JS website that allows for parents to send deliveries to their children in college through a volunteer system. 
  - Uses SQL in the backend in order to maintain a comprehensive database of all active deliveries for quick lookup.
  - Sends emails via secure SMTP for verification and notification of changes.
  - Employs a modern, easy-to-read UI to ensure that users are comfortable and can navigate the site easily.
